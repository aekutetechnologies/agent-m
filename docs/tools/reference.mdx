# Tools reference

The model calls tools through a registry with three kinds of gating: the
**permission gate** (risk-based approval), **plan mode** (only read-only tools
registered), and the **tool budget** warning. `--tools` / `--exclude-tools`
filter the active set; `--no-tools` disables everything.

## Read-only tools

| Tool | Arguments | Notes |
|---|---|---|
| `read` | `path`, `offset?`, `limit?` | Text file reader. 10 MB cap, 10 s timeout; refuses directories. **Read dedup**: re-reading the same `(path, offset, limit)` range while the file's mtime is unchanged returns a stub instead of re-reading — saves tokens on repeated reads. |
| `grep` | `pattern`, `path?`, `glob?` | `rg` with `--color never` + `--` terminator (regex walk fallback if `rg` is missing). |
| `find` | `pattern?`, `path?` | `fd` (or a walk fallback); result count clamped to 10 000. |
| `ls` | `path?` | Directory listing. |
| `search` | `query`, `path?` | **Symbol search** over a per-project index: JSON cache of file paths + symbol names with line numbers, rebuilt when any file under the root changes (tree-sitter grammars; skips vendored dirs like `node_modules`/`.git`/`__pycache__`). `/info` shows `search index: N files · N symbols`. |
| `web_fetch` | `url` | URL → readable text. 10 MB cap, 10 s timeout, `http(s)` only, with an SSRF guard (loopback/RFC1918/link-local targets blocked) re-applied on every redirect hop. |
| `web_search` | `query`, `max_results?` | SearXNG-style endpoint from `AGENT_M_SEARCH_URL` (clear error when unset); result count clamped. |
| `ask` | `question`, `options?`, `multi_select?` | Asks the human in the TUI (numbered options, `j/k` or ↑/↓ navigate, multi-select via space). Fails with a clear message when no ask gate is installed (headless/print mode). |

## Mutating tools

| Tool | Arguments | Notes |
|---|---|---|
| `bash` | `command`, `timeout?` | Runs via the user's shell in its own **process group**; on timeout the whole group is `SIGKILL`ed. With `AGENT_M_SANDBOX=1` the invocation runs under an OS sandbox (Seatbelt on macOS, Landlock/bwrap on Linux) that denies filesystem writes outside cwd/tmp. Output is capped: under 10 KB inline, larger output is offloaded to a file with a `read path="…"` pointer (50 KB inline ceiling). |
| `write` | `path`, `content` | Creates/overwrites a file (containment: resolved under cwd + `--allow-path` roots). Before-content is snapshotted for `/undo`. |
| `edit` | `path`, edits… | Exact-text multi-edit with a `similar`-based diff preview; snapshotted for `/undo` like `write`. |

## Output truncation & offload

Tool output is truncated at 50 KB (2000-line) ceilings. Above 10 KB the
truncation module offloads the full content to a numbered file under the
offload dir and returns an inline preview plus a `read path="…"` instruction,
so the model can page through large command output without flooding the
context window. Repeated reads of the same range are deduplicated by the
read cache (see `read` above).

## Risk tiers

Every tool call is classified by `RiskPolicy` (see
[Risk tiers](/trust/risk-tiers)): reads/searches are Low (auto-approved),
workspace writes are Medium, anything outside the cwd or touching `.git` is
High, and recursive deletes / device writes / opaque plugin or MCP tools are
Critical (always ask, even under `--yes`). In print mode without `--yes`,
mutating tools are not registered at all.
