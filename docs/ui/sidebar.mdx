# Right-side status sidebar (accordion)

The right side of the TUI is an accordion of collapsible sections. Click a
section header — or run `/sidebar <section>` — to collapse/expand it; the
collapsed state persists in `settings.json` under
`collapsedSidebarSections`.

## Sections

1. **Context** — model, tokens in/out, cache read %, cost, and context % of
   the model's window (updated as the agent works).
2. **Timing** — the most recent turn's elapsed time and the average over the
   last 10 turns.
3. **Flow** — while a flow runs: the flow name with a `done/total` counter, a
   progress bar, and one row per step — `✓` done (green), `▶` running
   (highlighted), `○` pending, `✗` failed.
4. **Plan** — the task list from `/plan` or a flow's plan step (`[x]`/`[ ]`
   with an `n/m` counter).

Sections appear only while they have content: Context is always present,
Timing after the first turn, Flow/Todos while a flow or plan is active.

## Controls

- `/sidebar` toggles the whole panel.
- `/sidebar context|timing|flow|todos` toggles one section (keyboard path).
- A mouse click on a section header toggles it.
- The sidebar auto-hides below 110 terminal columns.

## Status line

The bottom status line shows the model, message count, usage (↑ tokens, ↓
tokens, cost), context % (yellow above 70%, red above 90%), and while the
agent works it narrates the current tool call — `Reading src/app.rs…`,
`Running \`cargo test\`…`, `Searching \`TODO\`…` — instead of a bare spinner
(trust principle 1, transparency). After a `write`/`edit`, an `undo: /undo
(n)` hint appears so you can roll the change back.
